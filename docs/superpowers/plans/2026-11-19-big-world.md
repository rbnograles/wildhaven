# Big World (build 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 96×64 single-biome map with a 384×256 world of seven regions, about 49 landmarks to find and 14 signposts to fast-travel between.

**Architecture:** One shared data file, `assets/world/source/places.json`, holds every region, spawn, supply position, landmark and waypoint. `tools/build-map.py` reads it to generate terrain, a region grid and scenery; the pure JS modules read it for game rules. Discovery (regions, landmarks, waypoints) and travel are pure actions tested in Node; the renderer and DOM only display them.

**Tech Stack:** Vanilla JS ES modules, Vite 7, Phaser 4 (renderer only), `node:test`, Python 3 with numpy and Pillow, Prettier.

**Spec:** `docs/superpowers/specs/2026-11-19-big-world-design.md`

**Deviations from the spec (decided while planning):**
- Landmarks and waypoints live in one module, `src/data/places.js`, not two, because both come from the same JSON file.
- The "Frozen Tarn" is an ordinary pool ringed by snow; there is no separate ice terrain.
- The terrain, rivers and all 63 landmark/waypoint positions below were checked with a throwaway prototype: every point is in its named region and reachable on foot before scenery is added.

```js
// The map holds thousands of solid objects, so checking every one on every step would be slow.
// Instead the world is cut into big squares, and each square remembers the objects that touch it,
// like sorting books onto shelves so you only search one shelf.
const GRID = 256,
  PAD = 10, // the same padding `blocks` adds around each box
  gridCols = Math.ceil(WORLD.width / GRID),
  buckets = new Map();

for (const rect of OBSTACLES) {
  const [left, top, right, bottom] = rect;
  for (
    let cy = Math.max(0, Math.floor((top - PAD) / GRID));
    cy <= Math.floor((bottom + PAD) / GRID);
    cy++
  )
    for (
      let cx = Math.max(0, Math.floor((left - PAD) / GRID));
      cx <= Math.floor((right + PAD) / GRID);
      cx++
    ) {
      const key = cy * gridCols + cx;
      if (!buckets.has(key)) buckets.set(key, []);
      buckets.get(key).push(rect);
    }
}

/**
 * Says whether a spot is inside the solid base of any object the map placed.
 *
 * @param {number} x - World x position.
 * @param {number} y - World y position.
 * @returns {boolean} True if a tree, rock or building blocks the spot.
 */
export function hitsObstacle(x, y) {
  const near = buckets.get(Math.floor(y / GRID) * gridCols + Math.floor(x / GRID));
  return near ? blocks(near, x, y) : false;
}
```

```python
"""Makes stand-in art for the big-world biomes out of art that already exists.

It tints or redraws existing textures and sprites so the map can be built before real art is
generated. It NEVER overwrites: if a file is already there (a stand-in or real art) it is kept.
To replace a stand-in, generate the image from its .prompt.txt, save it over the PNG, and re-run
tools/build-map.py. Run: python tools/make-biome-standins.py
"""
import os
import numpy as np
from PIL import Image, ImageDraw

SRC = os.path.join(os.path.dirname(__file__), '..', 'assets', 'world', 'source')
OBJ = os.path.join(SRC, 'objects')
STYLE = ('Warm hand-painted 2D indie RPG style with clean soft outlines, matching the supplied character sprite '
         'reference: earthy greens, moss, warm ochre, soft warm light from the upper left. Elevated near-top-down '
         'orthographic game camera. No text, labels, UI, borders, grid lines or characters.')
REFERENCE = ('Input image: the supplied character sprite sheet is a STYLE REFERENCE ONLY; do not depict the '
             'characters or the sheet.')


# Writes one image and its prompt file, unless the image already exists.
def save(image, path, prompt):
    if os.path.exists(path):
        print('kept', os.path.relpath(path, SRC)); return
    image.save(path)
    open(path[:-4] + '.prompt.txt', 'w', encoding='utf-8').write(prompt + '\n')
    print('made', os.path.relpath(path, SRC))


# Builds the generation prompt for a seamless ground texture.
def texture_prompt(subject):
    return ('Use case: stylized-concept. Asset type: seamless ground texture for Wildhaven.\n' + REFERENCE + '\n'
            'Seamless tileable square ground texture for a top-down game, viewed straight down, filling the whole '
            f'image edge to edge: {subject}. Even lighting and even tone across the image, small-scale detail only, '
            'no large objects, no shadows from off-screen things, no vignette, no focal point. Left edge matches '
            'right edge and top edge matches bottom edge so it repeats without visible seams. Opaque square '
            '1024 x 1024 texture. The straight-down ground-plane view and even illumination take priority over '
            'directional shading.\n' + STYLE)


# Builds the generation prompt for one object sprite of about w x h pixels.
def object_prompt(subject, w, h):
    return ('Use case: stylized-concept. Asset type: isolated environment object sprite for Wildhaven.\n'
            + REFERENCE + '\n'
            f'Single isolated game object sprite on GENUINE TRANSPARENT ALPHA: {subject}. The whole object is visible '
            'with transparent padding on every side; nothing touches the image edge. No ground patch, no grass, no '
            'background, no cast shadow on the ground, no checkerboard. One object only. Compose to fit an '
            f'approximately {w} x {h} game sprite; it will be scaled to that size. Use ample clear alpha padding and '
            'retain an easily readable silhouette at small game size.\n' + STYLE)


# Recolours an image: first fades it towards grey by `gray` (0 to 1), then multiplies and adds per channel.
def recolor(image, mul, add=(0, 0, 0), gray=0.0):
    a = np.asarray(image.convert('RGBA')).astype(float)
    rgb = a[..., :3]
    lum = rgb.mean(axis=2, keepdims=True)
    a[..., :3] = np.clip((rgb * (1 - gray) + lum * gray) * np.array(mul) + np.array(add), 0, 255)
    return Image.fromarray(a.astype('uint8'))


def texture(name): return Image.open(os.path.join(SRC, f'{name}.png'))
def sprite(name): return Image.open(os.path.join(OBJ, f'{name}.png')).convert('RGBA')
def blank(w, h): return Image.new('RGBA', (w, h), (0, 0, 0, 0))


# ---- ground textures ---------------------------------------------------------------------
save(recolor(texture('grass'), (0.35, 0.36, 0.38), (185, 192, 202), gray=1).convert('RGB'), os.path.join(SRC, 'snow.png'),
     texture_prompt('soft packed snow in cool white with faint pale-blue drifts and a few tiny wind ripples; no '
                    'footprints, rocks or plants'))
save(recolor(texture('dirt'), (0.8, 0.8, 0.82), (10, 10, 14), gray=0.85).convert('RGB'), os.path.join(SRC, 'rock.png'),
     texture_prompt('weathered grey-brown canyon bedrock with fine cracks and small pebbles; no large boulders, '
                    'plants or water'))
save(recolor(texture('grass'), (0.45, 0.72, 0.5), (0, 6, 8)).convert('RGB'), os.path.join(SRC, 'jungle.png'),
     texture_prompt('dense dark-green jungle floor of moss, tiny ferns and fallen leaves; no flowers, roots or bare '
                    'earth'))

# ---- sprites derived from existing ones ----------------------------------------------------
save(recolor(sprite('pine'), (0.75, 0.85, 0.95), (55, 60, 70), gray=0.35), os.path.join(OBJ, 'snowy-pine.png'),
     object_prompt('one tall pine tree with heavy snow resting on its dark-green branches', 150, 210))
save(recolor(sprite('rocks-b'), (0.75, 0.9, 1.05), (40, 55, 70), gray=0.7), os.path.join(OBJ, 'ice-rock.png'),
     object_prompt('a low cluster of pale-blue ice-crusted rocks with frosted tops', 265, 135))
save(recolor(sprite('rocks-a'), (0.85, 0.83, 0.8), gray=0.9), os.path.join(OBJ, 'boulder.png'),
     object_prompt('a cluster of large rounded grey canyon boulders', 290, 170))
save(recolor(sprite('rocks-a').resize((290, 255), Image.LANCZOS), (0.7, 0.66, 0.62), gray=0.9), os.path.join(OBJ, 'cliff-rock.png'),
     object_prompt('a tall jagged outcrop of layered grey-brown canyon rock, taller than a person', 290, 255))
save(recolor(sprite('big-oak'), (0.45, 0.8, 0.5), (0, 5, 5)), os.path.join(OBJ, 'jungle-tree.png'),
     object_prompt('one broad tropical jungle tree with a dense deep-green canopy, buttress roots and hanging vines',
                   270, 320))
save(recolor(sprite('berry-bush'), (0.5, 0.95, 0.45), gray=0.2), os.path.join(OBJ, 'fern.png'),
     object_prompt('a low spray of broad bright-green jungle fern fronds', 150, 104))
save(recolor(sprite('oak').resize((200, 300), Image.LANCZOS), (0.8, 1.0, 0.55), (15, 10, 0)), os.path.join(OBJ, 'palm.png'),
     object_prompt('one leaning coconut palm tree with a slim curved trunk and a crown of long green fronds', 200, 300))
save(recolor(sprite('berry-bush'), (0.75, 0.6, 0.42), (40, 25, 10), gray=0.9), os.path.join(OBJ, 'dead-bush.png'),
     object_prompt('a dry leafless desert bush of tangled pale-brown twigs', 150, 104))

# ---- sprites drawn from simple shapes ------------------------------------------------------
OUT = 3  # outline width

cactus = blank(110, 170); d = ImageDraw.Draw(cactus)
for box in ((40, 12, 70, 164), (12, 60, 34, 112), (76, 44, 98, 100), (24, 96, 52, 114), (58, 84, 88, 102)):
    d.rounded_rectangle(box, 12, fill=(86, 140, 84), outline=(50, 84, 58), width=OUT)
save(cactus, os.path.join(OBJ, 'cactus.png'),
     object_prompt('one tall green saguaro cactus with two upturned arms', 110, 170))

ruin = blank(280, 220); d = ImageDraw.Draw(ruin)
for box in ((24, 60, 72, 212), (116, 20, 164, 212), (208, 96, 256, 212)):
    d.rectangle(box, fill=(214, 178, 120), outline=(150, 112, 70), width=OUT)
d.rectangle((14, 44, 176, 68), fill=(226, 192, 136), outline=(150, 112, 70), width=OUT)
d.rectangle((10, 200, 270, 216), fill=(196, 160, 104), outline=(150, 112, 70), width=OUT)
save(ruin, os.path.join(OBJ, 'sandstone-ruin.png'),
     object_prompt('a small ruin of three weathered sandstone columns on a cracked stone base, one still carrying a '
                   'broken lintel', 280, 220))

bridge = blank(420, 300); d = ImageDraw.Draw(bridge)
d.rounded_rectangle((6, 6, 414, 294), 14, fill=(140, 98, 60), outline=(88, 58, 34), width=OUT)
for x in range(40, 414, 34): d.line((x, 8, x, 292), fill=(104, 70, 42), width=2)
save(bridge, os.path.join(OBJ, 'bridge.png'),
     object_prompt('a flat wooden plank bridge deck seen from directly above, weathered boards side by side with '
                   'rope-bound edges, no railings, no water', 420, 300))

sign = blank(90, 130); d = ImageDraw.Draw(sign)
d.rectangle((40, 30, 50, 126), fill=(120, 84, 52), outline=(72, 48, 28), width=2)
d.polygon(((8, 14), (70, 14), (84, 30), (70, 46), (8, 46)), fill=(190, 150, 96), outline=(72, 48, 28))
save(sign, os.path.join(OBJ, 'signpost.png'),
     object_prompt('a wooden trail signpost: one upright post carrying a single arrow-shaped plank pointing right',
                   90, 130))
```

Replace the whole of `tools/build-map.py` with:

```python
"""Builds the Wildhaven sprite map from assets/world/source/.

Inputs : source/{grass,dirt,jungle,rock,snow,sand,water}.png  seamless ground textures
         source/objects/<name>.png + source/objects.json       one sprite per world object
         source/places.json                                    regions, spawns, supplies, landmarks, waypoints
Outputs: map/tileset.png    terrain tiles incl. generated soft transitions (64px, 1px extruded)
         map/wildhaven.json Tiled-format map: seven tile layers + "objects" layer + a region grid property
         map/overview.webp  small render of the whole map for the minimap and world map
The game reads collision from the JSON (water tiles + object footprints) and regions from its region grid.
Run: python tools/build-map.py [preview.png]
"""
import json, math, os, random, sys
import numpy as np
from PIL import Image

ROOT = os.path.join(os.path.dirname(__file__), '..', 'assets', 'world')
SRC, OUT = os.path.join(ROOT, 'source'), os.path.join(ROOT, 'map'); os.makedirs(OUT, exist_ok=True)
PLACES = json.load(open(os.path.join(SRC, 'places.json'), encoding='utf-8'))
TILE, COLS, ROWS, TEX = 64, 384, 256, 256
W, H = COLS * TILE, ROWS * TILE

# Terrains in paint order. A higher terrain is painted over a lower one, so the number is also its layer rank.
GRASS, DIRT, JUNGLE, ROCK, SNOW, SAND, WATER = range(7)
OVERLAYS = ['dirt', 'jungle', 'rock', 'snow', 'sand', 'water']   # rank 1..6; grass (rank 0) is the full ground layer

# ---- regions -----------------------------------------------------------------------------
# The world is an 8x8 grid of blocks, one letter per block. The letters are the `key` of each region in places.json.
LAYOUT = ['DDDPPSSS', 'DDDPPSSS', 'DDhhhhSS', 'CChhhhLL', 'CChhhhLL', 'CCJJJJLL', 'CJJJJJJL', 'CJJJJJJL']
BLOCK_W, BLOCK_H = W // 8, H // 8
BASE = {'D': SAND, 'P': GRASS, 'S': SNOW, 'h': GRASS, 'L': GRASS, 'C': ROCK, 'J': JUNGLE}
REGION_INDEX = {r['key']: i for i, r in enumerate(PLACES['regions'])}

# Says which region a point is in. The point is nudged by a few sine waves before the block grid is read, so the
# borders wobble like real coastlines instead of running in straight lines. The nudge is never more than 440 units.
def region_key(x, y):
    wx = x + 300 * math.sin(y / 830 + 1.7) + 140 * math.sin(y / 290 + 0.4)
    wy = y + 300 * math.sin(x / 910 + 0.6) + 140 * math.sin(x / 310 + 2.1)
    return LAYOUT[min(7, max(0, int(wy // BLOCK_H)))][min(7, max(0, int(wx // BLOCK_W)))]

# ---- water and special ground ------------------------------------------------------------
# Distance from a point to a path made of straight pieces (used for rivers and the dry riverbed).
def line_dist(pts, x, y):
    best = 1e9
    for (ax, ay), (bx, by) in zip(pts, pts[1:]):
        dx, dy = bx - ax, by - ay
        t = max(0, min(1, ((x - ax) * dx + (y - ay) * dy) / (dx * dx + dy * dy)))
        best = min(best, math.hypot(x - ax - t * dx, y - ay - t * dy))
    return best

# Where the sea starts on one row of the lagoon: everything in the lagoon to the right of this x is sea.
def coast(y): return 22000 + 450 * math.sin(y / 1700) + 150 * math.sin(y / 430)

RIVERS = [[(17000, 2500), (16200, 4800), (14800, 6400), (14600, 8600), (16200, 9900), (18800, 10300), (22600, 10500)],   # Frostpeak to the lagoon
          [(-200, 8200), (2200, 8600), (3600, 10200), (2600, 12200), (1500, 14000), (1900, 16600)]]                      # through the canyons
RIVER_HALF = 110
# Crossings: the river is replaced by dry ground within 190 of each point. BRIDGES also get a plank deck drawn on top.
FORDS = [(16600, 3650), (14700, 7500), (17500, 10100), (20200, 10375), (2900, 9400), (2050, 13100)]
BRIDGES = [(14700, 7500), (2900, 9400)]
DRY_BED = [(8800, 600), (6000, 2300), (3000, 2200), (600, 3800)]          # a walkable dirt riverbed across the desert
ISLANDS = [(23300, 8000, 330), (23700, 12500, 280), (23000, 14800, 240)]   # scenery only; nothing can reach them

SPAWN = {k: tuple(v) for k, v in PLACES['spawns'].items()}
POOLS = [(l['x'], l['y'] - l['pool'] - 120, l['pool']) for l in PLACES['landmarks'] if 'pool' in l]
# Every spot the player must be able to stand on. Water is pushed back from them and scenery is kept off them.
POINTS = (list(SPAWN.values()) + [tuple(p) for p in PLACES['supplies'].values()]
          + [(p['x'], p['y']) for p in PLACES['landmarks'] + PLACES['waypoints']])

# Says what the ground is at one point of the world.
def terrain(x, y):
    k = region_key(x, y); t = BASE[k]
    if k == 'D' and line_dist(DRY_BED, x, y) < 90: t = DIRT
    if k == 'L':
        edge = coast(y)
        if x > edge + 16: t = SAND if any(math.hypot(x - ix, y - iy) < r for ix, iy, r in ISLANDS) else WATER
        elif x > edge - 260 - 40 * math.sin(y / 180): t = SAND
    if any(line_dist(r, x, y) < RIVER_HALF + 25 * math.sin(x / 170 + y / 130) for r in RIVERS): t = WATER
    if any(math.hypot(x - px, y - py) < r for px, py, r in POOLS): t = WATER
    if t == WATER and any(math.hypot(x - fx, y - fy) < 190 for fx, fy in FORDS): t = DIRT
    if t != WATER:
        bx, by = SPAWN['builder']; sx, sy = SPAWN['scout']; vx, vy = SPAWN['survivor']
        if ((x - bx) / 400) ** 2 + ((y - by - 12) / 270) ** 2 < 1 + 0.15 * math.sin(x / 90 + y / 70): t = DIRT   # village clearing
        if math.hypot(x - sx + 30, y - sy + 50) < 150: t = DIRT                                                # scout's camp
        if t == GRASS and math.hypot(x - vx, y - vy) < 520: t = SAND                                          # the survivor's beach
    if t == WATER and any(math.hypot(x - px, y - py) < 130 for px, py in POINTS): t = SAND
    return t

corner = np.array([[terrain(x * TILE, y * TILE) for x in range(COLS + 1)] for y in range(ROWS + 1)])

# ---- tileset -----------------------------------------------------------------------------
tex = {n: np.asarray(Image.open(os.path.join(SRC, f'{n}.png')).convert('RGB').resize((TEX, TEX))).astype(float)
       for n in ['grass'] + OVERLAYS}
f = np.fft.fft2(np.random.default_rng(3).random((TEX, TEX)))
fy, fx = np.meshgrid(np.fft.fftfreq(TEX), np.fft.fftfreq(TEX), indexing='ij')
noise = np.real(np.fft.ifft2(f * np.exp(-(fx ** 2 + fy ** 2) * 900))); noise -= noise.mean(); noise /= np.abs(noise).max() * 2   # seamless, +-0.5
u = (np.arange(TILE) + 0.5) / TILE; U, V = np.meshgrid(u, u)

tiles = []   # RGBA arrays; gid = index + 1

# Adds 16 tiles to the tileset, one for each 64px square of a 256px texture (4 across, 4 down).
def variants(make):
    for py in range(4):
        for px in range(4): tiles.append(make(px, py))

# Cuts one tile-sized square out of a bigger picture.
def cut(a, px, py): return a[py*TILE:(py+1)*TILE, px*TILE:(px+1)*TILE]

first = {'ground': 1}
variants(lambda px, py: np.dstack([cut(tex['grass'], px, py), np.full((TILE, TILE), 255.0)]))
for name in OVERLAYS:
    first[name] = len(tiles) + 1
    for mask in range(1, 16):   # which of the four tile corners (TL, TR, BL, BR) hold this terrain
        tl, tr, bl, br = mask & 1, mask >> 1 & 1, mask >> 2 & 1, mask >> 3 & 1
        blend = tl * (1 - U) * (1 - V) + tr * U * (1 - V) + bl * (1 - U) * V + br * U * V

        # Paints one edge tile: solid where the corners say so, fading out elsewhere, with noise for a natural edge.
        def make(px, py, blend=blend, name=name):
            val = blend + cut(noise, px, py) * 0.5
            rgb = cut(tex[name], px, py).copy()
            alpha = np.clip((val - 0.5) / 0.05 + 0.5, 0, 1)
            if name == 'water':   # pale surf where water meets land
                foam = np.clip(1 - (val - 0.5) / 0.09, 0, 1)[..., None] * 0.75
                rgb = rgb * (1 - foam) + np.array([236, 250, 244.0]) * foam
            return np.dstack([rgb, alpha * 255])
        variants(make)

# Picks the tileset number (gid) for one map square; 0 means empty.
def gid(name, mask, tx, ty): return 0 if mask == 0 else first[name] + (mask - 1) * 16 + (ty % 4) * 4 + tx % 4

TS_COLS = 32; ts_rows = math.ceil(len(tiles) / TS_COLS); cell = TILE + 2
sheet = np.zeros((ts_rows * cell, TS_COLS * cell, 4), dtype='uint8')
for i, t in enumerate(tiles):
    y, x = (i // TS_COLS) * cell, (i % TS_COLS) * cell
    sheet[y:y+cell, x:x+cell] = np.pad(t.astype('uint8'), ((1, 1), (1, 1), (0, 0)), mode='edge')   # extrusion stops seams when zoomed
Image.fromarray(sheet).save(os.path.join(OUT, 'tileset.png'))

# ---- tile layers -------------------------------------------------------------------------
# A layer only paints a tile when one of the tile's corners is its own terrain. It then covers every corner of
```

```js
// The seven named regions of the world, and which one a spot is in.
// tools/build-map.py decides the borders and stores them in the map file as a grid of big squares,
// one digit per square; each digit is a region's place in the list in assets/world/source/places.json.

import { REGION_LIST } from '../data/places.js';
import { mapProperty } from './map.js';

const cell = mapProperty('regionCell'),
  cols = mapProperty('regionCols'),
  grid = mapProperty('regionGrid'),
  rows = grid.length / cols;

/** The size of the region grid: `cell` is a square's width in world units. */
export const REGION_GRID = { cell, cols, rows };

/**
 * Says which region one square of the grid belongs to.
 *
 * @param {number} cx - The square's column, from 0.
 * @param {number} cy - The square's row, from 0.
 * @returns {number} The region's index in `REGIONS`.
 */
export const regionIndexAt = (cx, cy) => Number(grid[cy * cols + cx]);

// A label on the world map needs one spot per region. The average of a region's squares can fall
// outside an L-shaped region, so the label goes on the region's own square nearest that average.
const centreOf = (index) => {
  const squares = [];
  for (let cy = 0; cy < rows; cy++)
    for (let cx = 0; cx < cols; cx++) if (regionIndexAt(cx, cy) === index) squares.push([cx, cy]);
  const ax = squares.reduce((sum, s) => sum + s[0], 0) / squares.length,
    ay = squares.reduce((sum, s) => sum + s[1], 0) / squares.length;
  const [cx, cy] = squares.reduce((best, s) =>
    Math.hypot(s[0] - ax, s[1] - ay) < Math.hypot(best[0] - ax, best[1] - ay) ? s : best,
  );
  return { x: (cx + 0.5) * cell, y: (cy + 0.5) * cell };
};

/** Every region. Fields: `id` (the save key), `name` (shown on screen), `x`/`y` (its label spot). */
export const REGIONS = REGION_LIST.map(({ id, name }, index) => ({ id, name, ...centreOf(index) }));

/**
 * Finds the region a spot is in. Every spot in the world is in exactly one.
 *
 * @param {number} x - World x position.
 * @param {number} y - World y position.
 * @returns {{id: string, name: string, x: number, y: number}} The region.
 */
export function regionOf(x, y) {
  const cx = Math.min(cols - 1, Math.max(0, Math.floor(x / cell))),
    cy = Math.min(rows - 1, Math.max(0, Math.floor(y / cell)));
  return REGIONS[regionIndexAt(cx, cy)];
}

 * Gives the name of the region the player is standing in, for the title at the top of the screen.
 *
 * @param {{x: number, y: number}} player - The player's position.
 * @returns {string} The region's name.
 */
export const regionAt = (player) => regionOf(player.x, player.y).name;
```

```js
// Counts how much of the world a character has found: per region for the HUD, and in total for
// the world map. It only reads the game state; it never changes it.

import { LANDMARKS, WAYPOINTS } from '../data/places.js';
import { REGIONS } from './regions.js';

/** Counts how many of `places` have their id in `foundIds`. */
const tally = (places, foundIds) => ({
  found: places.filter((p) => foundIds.includes(p.id)).length,
  total: places.length,
});

/**
 * Counts the places and signposts found in one region.
 *
 * @param {object} state - The game being played.
 * @param {string} regionId - The region to count, e.g. 'desert'.
 * @returns {{places: {found: number, total: number}, signposts: {found: number, total: number}}}
 */
export function regionProgress(state, regionId) {
  const here = (p) => p.region === regionId;
  return {
    places: tally(LANDMARKS.filter(here), state.landmarks),
    signposts: tally(WAYPOINTS.filter(here), state.waypoints),
  };
}

/**
 * Counts everything found in the whole world.
 *
 * @param {object} state - The game being played.
 * @returns {{regions: object, places: object, signposts: object}} Each as `{found, total}`.
 */
export function worldProgress(state) {
  return {
    regions: tally(REGIONS, state.discovered),
    places: tally(LANDMARKS, state.landmarks),
    signposts: tally(WAYPOINTS, state.waypoints),
  };
}
```

```js
   * Paints a map: either the whole world, or a window around the player for the corner minimap.
   *
   * World positions are shrunk to fit the canvas, like tracing a big map onto a postcard. On the
   * whole-world map, regions the player hasn't entered are dimmed. Found places are cream dots,
   * found signposts are gold diamonds, and the player is the white dot.
   *
   * @param {CanvasRenderingContext2D} ctx - The 2D canvas to paint on.
   * @param {object} state - The game being played.
   * @param {number} w - Canvas width in pixels.
   * @param {number} h - Canvas height in pixels.
   * @param {boolean} [local=false] - True to show only the area around the player.

  function drawMap(ctx, state, w, h, local = false) {
    // The part of the world this map shows, in world units.
    const vw = local ? MINI_VIEW : WORLD.width,
      vh = local ? (MINI_VIEW * h) / w : WORLD.height,
      vx = local ? Math.min(Math.max(state.player.x - vw / 2, 0), WORLD.width - vw) : 0,
      vy = local ? Math.min(Math.max(state.player.y - vh / 2, 0), WORLD.height - vh) : 0;
    const sx = overview.width / WORLD.width,
      sy = overview.height / WORLD.height;
    const px = (x) => ((x - vx) / vw) * w,
      py = (y) => ((y - vy) / vh) * h;

    ctx.clearRect(0, 0, w, h);
    ctx.drawImage(overview, vx * sx, vy * sy, vw * sx, vh * sy, 0, 0, w, h);

    // Dim the regions not yet entered, one grid square at a time.
    if (!local) {
      const cw = w / REGION_GRID.cols,
        ch = h / REGION_GRID.rows;
      ctx.fillStyle = 'rgba(24, 38, 30, 0.55)';
      for (let cy = 0; cy < REGION_GRID.rows; cy++)
        for (let cx = 0; cx < REGION_GRID.cols; cx++)
          if (!state.discovered.includes(REGIONS[regionIndexAt(cx, cy)].id))
            ctx.fillRect(cx * cw, cy * ch, cw + 0.5, ch + 0.5); // the extra half pixel hides hairline gaps
    }

    // Found places: small cream dots.
    ctx.lineWidth = 1.5;
    ctx.strokeStyle = '#294c3b';
    ctx.fillStyle = '#f7ecc5';
    for (const place of LANDMARKS) {
      if (!state.landmarks.includes(place.id)) continue;
      ctx.beginPath();
      ctx.arc(px(place.x), py(place.y), 3, 0, Math.PI * 2);
      ctx.fill();
      ctx.stroke();

    ctx.fillStyle = '#ffd166';
    for (const post of WAYPOINTS) {
      if (!state.waypoints.includes(post.id)) continue;
      const x = px(post.x),
        y = py(post.y);
      ctx.beginPath();
      ctx.moveTo(x, y - 5);
      ctx.lineTo(x + 5, y);
      ctx.lineTo(x, y + 5);
      ctx.lineTo(x - 5, y);
      ctx.closePath();
      ctx.fill();
      ctx.stroke();
    }

    // The player.
    ctx.fillStyle = '#ffffff';
    ctx.lineWidth = 2;
    ctx.beginPath();
    ctx.arc(px(state.player.x), py(state.player.y), 4.5, 0, Math.PI * 2);
    ctx.fill();
```

```js
import { travelTo } from '../actions/travel.js';
import { cancelAction } from '../animation/clips.js';
import { WAYPOINTS } from '../data/places.js';
import { WORLD } from '../world/map.js';
```

Add inside `setupDialogs`, above `toggleMap`:

```js
  /**
   * Travels to a found signpost and closes the map.
   *
   * Any gathering in progress is dropped, the camera jumps instead of flying across the world,
   * and the game saves at once so a refresh keeps the player where they arrived.
   *
   * @param {string} id - The signpost's id.
   */
  function travel(id) {
    const post = travelTo(session.state, id);
    if (!post) return;
    cancelAction(session.animator);
    session.renderer.resetCamera();
    $('map-dialog').close();
    save(session, ui, true);
    ui.hud.notify(`Travelled to ${post.name}`);
    ui.hud.update();
  }

  /** Puts one button on the map for each signpost the player has found. */
  function showWaypoints() {
    $('map-waypoints').replaceChildren(
      ...WAYPOINTS.filter((post) => session.state.waypoints.includes(post.id)).map((post) => {
        const button = document.createElement('button');
        button.className = 'map-waypoint';
        button.style.left = `${(post.x / WORLD.width) * 100}%`;
        button.style.top = `${(post.y / WORLD.height) * 100}%`;
        button.title = `Travel to ${post.name}`;
        button.setAttribute('aria-label', `Travel to ${post.name}`);
        button.addEventListener('click', () => travel(post.id));
        return button;
      }),
    );
  }
```

In `toggleMap`, call `showWaypoints();` on the line after `session.renderer.drawMap($('large-map'), session.state);`.
