# Sprite-map art: what to generate

The world is now built from ground textures and separate object sprites. The files currently in
`assets/world/source/` are stand-ins cut from the old painting. Replace them with the art below,
keeping the same file names, then run:

```bash
python tools/build-map.py
```

Do not run `tools/make-standin-art.py` again afterwards; it overwrites the files with stand-ins.

Shared style line (append to every prompt):

> Warm hand-painted 2D indie RPG style with clean soft outlines, matching the supplied character
> sprite reference: earthy greens, moss, warm ochre, soft warm light from the upper left. Elevated
> near-top-down orthographic game camera. No text, labels, UI, borders, grid lines or characters.

Attach `assets/characters/starting-characters-idle-v1.png` as the style reference each time.

## 1. Ground textures

Four files in `assets/world/source/`: `grass.png`, `dirt.png`, `sand.png`, `water.png`.
Square, any size from 256px up (the build resizes to 256). They must tile seamlessly, because each
one repeats across the whole map, and should be even in tone with no large features.

Prompt template:

> Seamless tileable square ground texture for a top-down game, viewed straight down, filling the whole
> image edge to edge: **{SURFACE}**. Even lighting and even tone across the image, small-scale
> detail only, no large objects, no shadows from off-screen things, no vignette, no focal point.
> Left edge matches right edge and top edge matches bottom edge so it repeats without visible seams.

| File | {SURFACE} |
| --- | --- |
| `grass.png` | short meadow grass in warm yellow-green with a few tiny darker tufts; no flowers, rocks or bare patches |
| `dirt.png` | trodden pale ochre village dirt with a few tiny pebbles; no footprints, ruts or grass |
| `sand.png` | fine pale golden beach sand with faint wind ripples; no shells, stones or footprints |
| `water.png` | shallow turquoise sea water with soft small wave highlights; no foam lines, rocks or shoreline |

The soft edges between surfaces (grass to dirt, sand to sea with surf) are generated by the build
script, so no transition tiles are needed.

## 2. Object sprites

One PNG per object in `assets/world/source/objects/`, on genuine transparent alpha. Sizes are a
guide (1 pixel = 1 world unit; the character is about 112 tall). Other sizes work, but update
`origin` and `footprint` for that object in `assets/world/source/objects.json` to match.

Prompt template:

> Single isolated game object sprite on GENUINE TRANSPARENT ALPHA: **{OBJECT}**. The whole object
> is visible with transparent padding on every side; nothing touches the image edge. No ground
> patch, no grass, no background, no cast shadow on the ground, no checkerboard. One object only.

| File | Approx. size | {OBJECT} |
| --- | --- | --- |
| `tent.png` | 250 x 185 | small patched canvas ridge tent with a wooden supply crate beside it |
| `log.png` | 150 x 90 | fallen tree log lying on its side |
| `campfire.png` | 150 x 95 | cold campfire: ring of stones around charred sticks, no flames |
| `house-a.png` | 435 x 335 | abandoned timber-framed cottage, orange clay tile roof with a hole, ivy on the walls, stone chimney, open doorway facing the viewer |
| `house-b.png` | 475 x 355 | abandoned timber-framed cottage with a dormer window, damaged orange tile roof, short wooden fence at one side |
| `house-c.png` | 455 x 355 | abandoned timber-framed cottage, collapsed roof section, barrels by the door |
| `workshop.png` | 595 x 380 | ruined open-sided blacksmith workshop: broken tile roof on timber posts, stone forge and chimney, anvil, cart wheel |
| `ship.png` | 530 x 525 | small wrecked wooden sailing ship lying tilted, broken mast with torn sails, splintered hull; no water or sand |
| `pine.png` | 150 x 210 | single conifer pine tree |
| `pines.png` | 225 x 270 | two conifer pines of different heights standing close together |
| `oak.png` | 295 x 280 | broadleaf tree with a round yellow-green canopy and visible trunk |
| `big-oak.png` | 270 x 320 | large old broadleaf tree, wide canopy, thick trunk |
| `rocks-a.png` | 290 x 170 | cluster of three grey boulders with moss |
| `rocks-b.png` | 265 x 135 | two grey boulders, one large and one small |
| `beach-rock.png` | 205 x 125 | weathered pale boulder with a little moss |
| `flowers.png` | 255 x 155 | low patch of pink and yellow wildflowers, seen from above |

To add a new kind of object: save `objects/<name>.png`, add a `<name>` entry to `objects.json`, and
place it in `tools/build-map.py` (or open `assets/world/map/wildhaven.json` in the Tiled editor
and add a point named `<name>` on the `objects` layer).
